## 当前结论

- 新建独立 `HTHIUM.Mes.sln` 和浏览器前端工程，正式 MES 采用 B/S 架构。
- 后端采用 .NET 10 LTS、ASP.NET Core Web API、MySQL。
- 第一阶段采用模块化单体，不引入微服务复杂度。
- HTHIUM 单机平台是边缘客户端，负责采集、业务判断、本地缓存和可靠上传。
- MES 负责统一身份、数据接入、业务存储、查询、统计、权限和后续前端支撑。
- 正式系统不包含 Central WPF；监控、运维、配置和业务操作全部由浏览器前端完成。
